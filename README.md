# 浜名湖うなぎ

静岡県・浜名湖のうなぎと食文化を紹介する、静的な1ページサイトです。

- 汽水湖・浜名湖の恵みと、1879年から続く養殖の歴史
- 稚魚から蒲焼きまでの手仕事
- 蒲焼き・白焼きなどの味わい方
- 弁天島・館山寺温泉・今切口などの周辺案内
- FAQ、アクセス

## 構成

```
index.html          ページ本体
assets/style.css    スタイル
assets/script.js    ナビゲーション、スクロール演出
assets/favicon.svg  ファビコン
assets/ogp.png      OGP画像
```

## ローカルで見る

```bash
python3 -m http.server 8000
```

`http://localhost:8000/` を開いてください。
